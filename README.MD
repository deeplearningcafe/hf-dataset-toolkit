## Overview

The **HF Dataset Toolkit** is a zero-disk multimodal data curation pipeline designed for training modern Diffusion Transformers (DiTs) using Flow Matching (FM). Built to scale text-to-image foundation models from 256px and 512px pretraining up to 1-Megapixel (1MP) production stages, this toolkit provides a fully reproducible pipeline based on the open recipe established in [**i1: A Simple and Fully Open Recipe for Strong Text-to-Image Models**](https://arxiv.org/abs/2606.11289) (Zeng et al., 2026).

Rather than storing hundreds of gigabytes of raw uncompressed images or precomputed latents locally, the toolkit streams datasets directly from Hugging Face Hub, matches each image on-the-fly with rich synthetic captions generated by **Qwen3-VL-30B-A3B**, enforces NovelAI aspect-ratio bucketing, encodes images into high-efficiency **AVIF** byte streams, packages them into balanced Parquet shards, pushes them to Hugging Face, and immediately purges local scratch space.

The resulting dataset schema is strictly backwards-compatible with anime/Danbooru training pipelines (such as `toy-diffusion` and `asuka-fm`), enabling general-domain benchmark training.

## Key Features

* **Zero-Disk Ephemeral Sharding**: Streams source datasets over HTTP. Shards are written locally to temporary scratch space, pushed to Hugging Face Hub, and deleted immediately—keeping local disk requirements bounded to a single shard (~500MB to 1GB).
* **i1 Multi-Caption Alignment**: Streams and aligns the 5 synthetic captions per image from `zlab-princeton/i1-captions` (Qwen3-VL-30B-A3B) without downloading the full 153 GB / 166M-row caption corpus to disk.
* **Sliding Dataset Window (`max_active_sources`)**: Dynamically bounds active concurrent dataset streams (e.g., $K=3$). As soon as an active dataset reaches its sampling quota or is exhausted, it is cleanly retired, its memory and connections are freed via garbage collection, and a pending dataset from the pool is promoted.
* **AVIF Byte Encoding**: Images are normalized, EXIF-transposed, and encoded into the AVIF format at configurable quality (default: 80). This reduces disk and network transmission size by over 70% compared to WebP/PNG while preserving high-frequency image details crucial for VAE reconstruction.
* **NovelAI Dynamic Aspect Ratio Bucketing**: Assigns images dynamically to aspect ratio buckets (divisible by 64 for VAE downsampling factors of 8 or 16). Images with extreme aspect ratios or resolutions below the minimum threshold (`min_resolution: 512`) are filtered out automatically.
* **Text Token Tiering**: Calculates token lengths using the specified tokenizer (e.g., `Qwen/Qwen3.5-0.8B`) and assigns samples to length tiers (`[77, 152, 227]`), allowing downstream loaders to pack batches with minimal sequence padding.
* **Class & Synset Balancing**: Prevents domain collapse by capping samples per category in classification datasets (e.g., ImageNet synsets and FLUX-Reason task types).
* **Danbooru Schema Compatibility**: Exports shards using fields familiar to anime/multimodal pipelines (`booru_id`, `image`, `prompt`, `bucket_idx`, `tier`, `aesthetic_tier`, `tag_weight`), allowing drop-in reuse of dataloaders across projects.

## Workflow and Usage

The pipeline is managed via the CLI in `main.py`.

### 1. Configure the Target Settings
Review or modify `configs/default_config.yaml` to specify your target Hugging Face repository, dataset sources, sampling limits, and resolution stage:

```yaml
experiment_name: "i1_balanced_photorealistic"
hf_repo_id: "your-hf-username/i1-curated-1mp"
hf_token: null # Uses huggingface-cli credentials if null

datasets:
  - "imagenet22k"
  - "fluxreason"
  - "gptedit"
  - "midjourneyv6"
  - "pexels"
  - "rendered_text"
  - "textatlas"

max_active_sources: 3
samples_per_source: 100000
samples_per_shard: 10000
min_resolution: 512
```

### 2. Execute the Dataset Sharding Pipeline
Run the builder command:

```bash
python main.py build-dataset --config-path configs/default_config.yaml
```

The process executes as follows:
1. Shuffles the list of candidate datasets and loads up to `max_active_sources` (default: 3) into the active window.
2. Streams image samples and fetches their matching 5 synthetic captions from `zlab-princeton/i1-captions`.
3. Verifies resolution constraints and assigns aspect-ratio buckets.
4. Populates an in-memory buffer, draws a balanced slice across active sources, and shuffles the records.
5. Writes `data_shard_XXXXX.parquet` to scratch storage, uploads it directly to your target Hugging Face repository, and deletes the local shard.
6. When an active dataset exhausts its sample quota, it is cleanly evicted and a new pending source is promoted.
7. Generates and uploads the final `metadata.json` containing bucket statistics and 1MP sample counts.

## Configuration Guide

The `configs/default_config.yaml` file controls all stages of execution:

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `hf_repo_id` | `str` | `"your-hf/dataset"` | Target repository on Hugging Face Hub. |
| `datasets` | `list[str]` | `[...]` | Active subsets to curate (e.g., `imagenet22k`, `fluxreason`, `textatlas`). |
| `max_active_sources` | `int` | `3` | Number of datasets streamed concurrently (prevents memory and network bottlenecks). |
| `samples_per_source` | `int` | `100000` | Subsampling quota per dataset (matching Table 7 of the *i1* paper). |
| `samples_per_shard` | `int` | `10000` | Number of balanced samples packed per Parquet file. |
| `min_resolution` | `int` | `512` | Hard minimum for `min(width, height)`. Discards lower-resolution images. |
| `max_res_area` | `[int, int]` | `[1024, 1024]` | Target maximum latent token budget for NovelAI bucketing. |
| `max_dim_limit` | `int` | `1536` | Maximum allowed dimension for either width or height. |
| `base_res` | `[int, int]` | `[1024, 1024]` | Anchor resolution explicitly inserted into the bucket registry. |
| `divisible` | `int` | `64` | Bucket dimensions must be divisible by this factor (matches VAE patch sizes). |
| `max_log_ar_diff` | `float` | `0.35` | Maximum log aspect-ratio distance before an image is pruned. |
| `avif_quality` | `int` | `80` | Compression quality for in-memory AVIF encoding (80 yields near-lossless RGB). |
| `length_tiers` | `list[int]` | `[77, 152, 227]` | Sequence length tiers for bucketed token padding. |
| `tokenizer_name` | `str` | `"Qwen/Qwen3.5-0.8B"` | Tokenizer used to calculate caption lengths. |
| `vae_downsample_factor`| `int`| `8` | Downsampling ratio of target VAE (8 for SD/FLUX, 16 for next-gen DiTs). |

## Downstream Training Integration

The exported schema is:

```python
import pyarrow as pa

schema = pa.schema([
    ("booru_id", pa.string()),         # Formatted as "{source}_{id}" (e.g., "fluxreason_10492")
    ("image", pa.binary()),            # AVIF-compressed image byte array
    ("prompt", pa.list_(pa.string())), # 5 synthetic captions from i1
    ("bucket_idx", pa.int32()),        # Index into bucket_resolutions
    ("target_width", pa.int32()),      # Assigned bucket width
    ("target_height", pa.int32()),     # Assigned bucket height
    ("original_width", pa.int32()),    # Source image raw width
    ("original_height", pa.int32()),   # Source image raw height
    ("aspect_ratio", pa.float32()),    # original_width / original_height
    ("tier", pa.int32()),              # Sequence length tier (e.g., 77, 152, 227)
    ("aesthetic_tier", pa.int32()),    # 3 if min_edge >= 1024, else 2
    ("tag_weight", pa.float32()),      # Loss weighting coefficient (default: 1.0)
])
```
